# Julia findings

Edge-case findings in Julia Base and its standard libraries (ranges, LinearAlgebra, SparseArrays, Statistics, compiler intrinsics), each with a minimized reproducer and a write-up in issue form. They come from differential testing: the same operation run on two representations that must agree (a range and its collected vector, a structured or sparse matrix and its dense form, a narrow integer type and a wide reference), with every mismatch classified by value, element type, exception type or outcome, then triaged by hand against existing issues.

Maintainers asked that these not be reported one by one as bot comments on the Julia repository, so they are collected here instead. Each entry also has an issue in this repository that references the related upstream issues in full form, so that the upstream timelines show a cross-reference without any comment being posted. Anyone is welcome to pick one up, open an upstream issue or pull request from it, or tell us that it is a duplicate or intended behaviour. See [CONTRIBUTING.md](CONTRIBUTING.md) for the rules, which apply to people and to automated agents.

Tested on Julia 1.13.3 and the official nightly 1.15.0-DEV.720 (LinearAlgebra 1.13.0 / 1.14.0, SparseArrays 1.13.0 / 1.14.0, Statistics 1.11.2 bundled / 1.11.5 registry), unless a finding says otherwise. Each entry records the exact versions, the mechanism in the source, and the deduplication searches that were run. "Comment" entries are written as follow-ups to an existing issue; "issue" entries matched no existing report when they were written.

## Reproducers

Every `.jl` file is standalone: `julia --startup-file=no path/to/script.jl` prints `REPRODUCED` on the versions named in its entry (the Statistics scripts need `using Statistics` to resolve; use a project with Statistics 1.11.5 where the entry says so). The scripts assert the observed behaviour, so a failing assertion means the behaviour changed on your Julia.

## Methodology

The finding entries describe the operation, the two paths that disagree, the mechanism in the source, the versions checked and the searches run for duplicates. The differential harness itself is a separate research project.
